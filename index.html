@gcu/capsule

A compact string that resolves to bytes — carried inline (URL fragment / QR) or referenced. This page runs the real package (src/index.js) entirely in your browser; nothing is sent anywhere.

GitHub Spec Guide Roadmap offline · zero-dep
Encode

Type anything. It's UTF-8 → deflate-raw → the three equivalent inline forms — all decode to the same bytes (§17).

Decode

Paste a capsule (inline: / i: / q:), a full share URL, or a #fragment. Reference schemes (gh:, gist:, …) resolve over the network.

The q: fragment gotcha · §6.4.1

base45 contains two characters a URL fragment can't carry — space and %. Watch them escape, and round-trip back.
